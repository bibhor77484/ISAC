1. '_full' files indicate the scenario when all the symbols are pilot symbols

2. '_interp' files indicate the scenario when SRS comb = 2 is used and then interpolation is done to estimate the whole channel estimate. Then, SRS signal that with no comb is used to generate the received signal from the estimated channel.

3. '_hardware' files indicate the scenario when SRS comb = 2 is used and then interpolation is done to estimate the whole channel estimate. Then, the original pilot symbols with comb = 2 is used to generate the received signal from the estimated channel.
